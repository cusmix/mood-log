# Mood Log

毎日の気分を記録して、あとから振り返るための学習用Webアプリです。HTML / CSS / JavaScriptで動作し、アプリ用のサーバー処理やデータベースは使用しません。

このアプリは診断・予測・医療的または心理的判断を行いません。数値は保存・集計のための対応値であり、ユーザーを評価する点数ではありません。

## 使用技術と対応想定

- HTML：画面とフォームの構造
- CSS：レスポンシブな配置、選択・フォーカス表示、棒グラフ
- JavaScript：入力検証、保存・更新・削除、履歴、集計、日付変更保護
- ブラウザ標準のlocalStorageとIntl.Segmenterなどを使用
- 外部フレームワーク、外部JavaScript、外部CSS、外部フォント、分析ツール、広告は使用していません。
- 対応想定は、現在のPC・スマートフォン版Chromeです。対応想定は実機での動作保証を意味しません。

## ファイルと開き方

| ファイル | 内容 |
| --- | --- |
| index.html | アプリ説明、RECORD・INSIGHTS・HISTORYの画面 |
| style.css | 画面の見た目、狭い画面への対応、グラフ |
| script.js | アプリの処理 |
| README.md | 使い方と保存に関する説明 |

3つのアプリファイルを同じフォルダーに置き、PCではindex.htmlをChromeで開いて確認できます。パッケージのインストールやビルドは不要です。JavaScriptとブラウザの保存領域を利用できる必要があります。

ファイルを直接開く場合のlocalStorageの扱いはブラウザ環境に依存します。保存後に再度開いて記録が残ることを確認してください。開く場所やURLを変更した場合、以前の記録が自動で引き継がれるとは限りません。

## 主な機能

### RECORD：今日の記録

1. 今日の気分を5段階から1つ選びます。
2. 必要に応じて「ひとこと」を入力します。
3. 「保存する」を押します。今日の記録がすでにあれば「更新する」と表示されます。

1日1件です。同じ日に何度保存しても、その日の記録を更新します。日付は端末の現地日付を使い、任意の日付を選ぶ操作はありません。ページを開くと、保存済みの今日の記録をフォームへ復元します。保存・更新後も入力内容は残ります。

ひとことは任意で、空欄でも保存できます。文字数カウンターを表示し、最大200文字まで受け付けます。Intl.Segmenterが使える場合は、見た目の1文字に近いgrapheme単位で数えます。使えない場合はUnicodeコードポイント単位で数え、複合絵文字などを複数文字と数える場合があることを画面で案内します。カウンター・入力検証・保存データ検証には同じ計算方法を使用します。

200文字を超えても文章を切り捨てず、エラーを表示して保存を止めます。日本語IMEの変換中は入力エラーの更新と保存処理を待ちます。

### 気分の5段階

| 内部値 | 表示 |
| --- | --- |
| 1 | 😣 つらい |
| 2 | 😔 いまいち |
| 3 | 😐 ふつう |
| 4 | 🙂 いい感じ |
| 5 | 😄 とてもいい感じ |

### HISTORY：これまでの記録

日付の新しい順に、日付・気分・ひとことを表示します。空のひとことは「ひとことなし」、記録が0件なら「まだ記録がありません」と表示します。

各記録の「削除する」から、その日だけを削除できます。確認ダイアログでキャンセルした場合は変更しません。削除は取り消せません。今日の記録を削除するとフォームを初期状態へ戻し、過去の記録を削除した場合は今日の入力を保持します。

ひとことはHTMLとして解釈せず、文字として表示します。

### INSIGHTS：直近7日間の振り返り

対象期間は、画面の基準日である今日と過去6暦日です。最後の7件や過去168時間ではありません。月末・年末・うるう年を含むカレンダーの日付で計算します。

| 項目 | 計算と表示 |
| --- | --- |
| 記録日数 | 期間内の記録件数。例：4 / 7日 |
| 平均気分 | 記録のある日のmoodの合計を記録日数で割り、小数第1位まで表示。未記録日は除外 |
| 最も多かった気分 | 絵文字とラベルを表示。同率の場合は該当するものすべてを内部値1→5の順に表示 |
| 累計記録日数 | 全期間の記録件数 |

期間内の記録が0件なら、平均・最多は「—」です。例えば2・3・3・4の4件なら、平均は3.0、最多は「😐 ふつう」です。平均は1〜5の対応を使った振り返り用の参考値として説明し、「点」とは表現しません。全期間について平均・最多は計算しません。

### 7日間グラフ

HTMLとCSSの棒グラフで、INSIGHTSと同じ7暦日を表示します。左が6日前、右が今日です。高さは1〜5の固定スケールで、1は20％、5は100％です。未記録日には棒を作らず「未記録」と表示します。

7日分の日付と気分ラベルを文字でも表示し、色・高さ・絵文字だけに情報を依存させません。Canvasや外部グラフライブラリは使用していません。評価・診断・心理的解釈は付けません。

保存・更新・削除が成功すると、履歴・集計・グラフを再読み込みなしで更新します。書き込み失敗時は成功通知を出さず、保存済みの表示を維持します。

## 日付変更の保護

ページを開いた時点の現地日付を基準日として保持します。保存・更新・削除の直前と、ページへ戻ったときに日付を確認します。0時にタイマーで自動切り替えする仕組みではありません。

日付変更を検出すると、その操作を止めて通知します。気分・ひとこと・保存済み履歴は検出だけでは変更しません。旧日にも新日にも自動保存しません。

「新しい今日へ切り替える」を押し、確認ダイアログで承認すると、新しい日の保存済み記録を読み込みます。記録がなければ空の新規入力状態になります。切り替え時は未保存の入力が置き換わります。必要な内容は切り替え前に控えてください。キャンセルした場合は入力を保持します。

切り替え後は日付・保存／更新ボタン・集計・グラフの基準日をそろえます。切り替え自体では保存しません。保存データが不正な場合は、入力を保持して切り替えを中止します。

## データの保存方法とエラー時の動作

記録はブラウザのlocalStorageに、キー「mood-log」でJSON文字列として保存します。形式は次のとおりです（値は説明用の例）。

```json
{
  "version": 1,
  "records": [
    { "date": "2026-09-25", "mood": 3, "note": "散歩をした" }
  ]
}
```

- date：YYYY-MM-DD形式の実在する日付。同じ日付は1件のみ。
- mood：1〜5の整数。
- note：文字列。文字数はRECORDと同じ方法で検証。
- 集計結果やグラフは保存せず、検証済みrecordsから計算します。

読み込み時と保存・削除の直前に、JSON・version・構造・値・日付の重複などを検証します。壊れたデータ、不正な値、未対応version、読み込み失敗を検出すると、記録保護の案内を表示して保存・更新・削除を停止します。不正な記録から履歴・集計・グラフを生成しません。元データの自動修復・自動初期化は行わず、初期化ボタンもありません。

書き込み失敗時はエラーを表示します。入力内容を消したり、保存・削除に成功したように表示したりしません。

## プライバシーと保存上の注意

- アプリは記録内容をサーバーや外部サービスへ送信しません。
- 記録は利用中のブラウザのlocalStorageに保存されます。
- ブラウザの保存データを削除すると、記録も消えます。
- 端末・ブラウザ間で同期されません。
- 自動バックアップ、データのエクスポート・インポート、復元機能はありません。
- 未保存の入力を、ページ再読み込み後に復元する機能はありません。
- ログイン、パスワード保護、アプリ独自の暗号化はありません。同じブラウザを使う人が記録を閲覧できる可能性があるため、共有端末では注意してください。
- localStorageは秘密情報を保護する保管庫ではありません。入力する内容は利用環境に合わせて判断してください。

## アクセシビリティと表示

気分選択はfieldset・legendと標準radio buttonで構成し、文字ラベルを付けています。選択マークと枠線で選択状態を示し、キーボードのフォーカスを可視化しています。入力欄にはlabelがあり、処理結果やエラー、日付変更は読み上げ用の通知領域でも伝えます。

グラフの日付・気分は文字で確認できます。装飾用の棒と目盛りは読み上げ対象から外しています。狭い画面では選択肢や集計欄の配置を変更し、文字を折り返します。

PC・スマートフォンChromeでの実際の表示、キーボード操作、スクリーンリーダー、ブラウザズームの最終確認は別途必要です。本書はコードから確認した実装を説明するもので、実機確認済みを示すものではありません。
